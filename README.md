# student-score-analysis

面向采用 **3+1+2 选科模式**的普通高中年级管理者、班主任和学科教师的本地成绩分析工具。一套系统管理一所学校，支持单次考试分析和多次考试追踪。

## 功能

| 场景 | 内容 |
| --- | --- |
| 整体看板 | 参考人数、班级覆盖、最高/最低分、均分、标准差、上线结构和历次比较 |
| 班级分析 | 班级与年级比较、目标达标、上线、临界及历次变化 |
| 学科分析 | 原始分与赋分口径、学科均分、划线、命中率和贡献率 |
| 学生群体 | 分数段、临界窗口、历次成绩矩阵和共同学生转化 |
| 个体追踪 | 单次学情、各科表现、年级排名与历次变化 |
| 导入与导出 | Excel 预检、问题提醒、确认入库；按考试和班级导出成绩表 |

## 使用方式

Windows 10/11 x64 用户使用安装包，无需安装 Python。首次启动自动创建空数据库，没有真实学生资料。本版本免登录、离线运行，无需账号、验证码或云端授权配置。

1. 安装并启动程序，浏览器自动打开本机页面。
2. 使用 `templates/upload/` 的基础信息和成绩模板，先导入基础信息，再导入成绩。
3. 配置各次考试、各方向的目标和分数线，选择分析范围。
4. 在导出中心下载班级成绩表压缩包。

详细步骤见 [使用指南](docs/使用指南.md)。统计定义见 [核心业务规则](docs/核心业务规则.md) 与 [字段追踪矩阵](docs/字段追踪矩阵.md)。

## 统计范围

年级均分和排名来自本校、同届、同场考试、同方向的有效成绩；选择某班或搜索学生不会缩小年级基准。物理和历史方向分开比较。均分按有效学生成绩计算，不对班均分再求平均。有效零分计入，缺失和未选考不当作零分。

选考科目必须提供赋分，本工具不代替省级赋分系统。上传的中文排名只作核对；同分同名次并跳号，显示和导出采用系统计算值。目标、特控、211、985 等是可配置的教学管理指标，不是录取预测或官方录取结论。

## 数据存储

- 服务仅监听 `127.0.0.1`，不提供局域网共享。
- 学生、成绩、上传文件和导出文件保存在本机，应用不连接云端认证或数据服务。
- 安装版数据目录：`%LOCALAPPDATA%\StudentScoreAnalysis`。源码运行使用项目内的 `instance/`。
- 关闭浏览器不会停止服务；请使用“完全退出程序”。卸载保留本机数据。
- 本机其他使用者能够在打开的程序中访问数据；SQLite 文件未加密，请使用受保护的 Windows 账户和适当的磁盘保护。

## 从源码运行

需要 Python 3.10 或更新版本。示例使用 Windows PowerShell：

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -B run.py
```

无需填写后台配置，窗口会打开实际可用的本机端口。演示数据仅在显式运行 `flask --app run.py seed-demo` 命令时生成，使用明确化名，可在数据管理中单独确认清除。
