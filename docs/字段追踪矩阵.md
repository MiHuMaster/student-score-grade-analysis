# 结果字段追踪矩阵（本校年级版）

| 结果字段 | 指标口径 | 主要原始字段 | 规范数据表 | 缺失影响 |
|---|---|---|---|---|
| 参考人数 | 正常参考且有效总分的去重 `student_id` | 学号＋姓名、总分赋分或六科有效分 | `exam_results` | 该学生不进入分母 |
| 最高/最低/平均分 | 当前范围有效总分聚合 | 总分赋分优先，缺失时由完整六科推导 | `exam_results` | 显示暂无有效成绩 |
| 总体标准差 | 有效总分总体标准差 | 同上 | 计算服务实时计算 | 显示暂无有效成绩 |
| 特控/211/985 上线 | 有效总分 ≥ 对应方向总分线 | 分数线表、方向、有效总分 | `score_lines`、`exam_results` | 明确提示缺少对应方向分数线 |
| 上线率 | 上线人数 ÷ 同范围有效参考人数 | 同上 | 计算服务 | 分母为零时无法计算 |
| 班级目标完成率 | 某班特控实际上线人数 ÷ 该班目标特控人数 | 特控目标、班级、上线人数 | `class_targets` | 未设置目标时无法计算 |
| 目标达标班级比例 | 已达到目标的班级数 ÷ 已设置有效目标的班级数 | 特控目标、班级、上线人数 | `class_targets` | 未设置目标的班级不进分母 |
| 按线分段 | 六段统一左闭右开并核对总人数，最高档不设右界 | 特控/211/985 线、有效总分 | 分段服务 | 缺任一分数线则不可计算 |
| 固定分数段 | 50 分步长，末段含满分 | 考试满分、有效总分 | 分段服务 | 满分缺失则使用考试配置 |
| 单科线 | 上线学生该科均分 × 总分线 ÷ 上线学生总分均分 | 单科有效成绩、总分线 | `subject_scores`、`score_lines` | 无上线学生或均分为零时无法计算 |
| 学科命中率 | 双上线人数 ÷ 学科上线人数 | 单科线、总分线 | 学科服务 | 分母为零时无法计算 |
| 学科贡献率 | 双上线人数 ÷ 总分上线人数 | 同上 | 学科服务 | 分母为零时无法计算 |
| 临界生人数 | `[线－窗口, 线)`，窗口 40/60/90 | 特控线、有效总分 | 群体服务 | 缺线时无法计算 |
| 临界生转化 | 上次临界且本次上线的共同学生 | 稳定 `student_id`、相邻考试、两次分数线 | 群体服务 | 缺上一场或匹配不足时说明原因 |
| 年级均分差 | 班级均分－同方向年级均分 | 本校同届同考试同方向已导入有效成绩 | `grade_statistics` 实时聚合 | 显示暂无年级数据 |
| 年级均分比 | 班级均分 ÷ 同方向年级均分 | 同上 | `grade_statistics` 实时聚合 | 年级均分为零或缺失时无法计算 |
| 年级排名 | 1＋同方向成绩严格更高的人数，同分跳号 | 总分或该科有效成绩 | `grade_statistics` 实时聚合 | 无有效分数不产生名次 |
| 年级覆盖 | 已导入有效人数、班级数及单科有效人数 | 同考试去重结果、班级和学科成绩 | `exam_results`、`subject_scores` | 不假定数据覆盖全年级 |
| 学生个体趋势 | 总分、得分率、排名和线差并列展示 | 稳定 `student_id`、多次考试成绩 | 学生个体服务 | 只有一场考试时不下进退步结论 |

说明：班级成绩表导出与页面共用年级统计服务；导出排名按同校、同届、同场考试、同方向计算。
