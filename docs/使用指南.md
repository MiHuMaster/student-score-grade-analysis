# 使用指南

## 安装与首次启动

双击安装包，选择安装位置和桌面快捷方式。程序与其他应用采用独立目录；卸载仅删除程序，不删除成绩。

首次启动自动打开本机浏览器。默认没有学生和考试。无需登录或联网配置，直接进入成绩分析页面。

## 准备数据

安装后的上传模板位于程序目录 `_internal/templates/upload/`；源码模板在 `templates/upload/`。

基础信息包含“学校信息”和“学生信息”，填写本校名称、届别、班级、学号、姓名及选科。每套系统只管理一个学校。成绩模板包含物理、历史两个方向；填写原始分及已选科目的赋分，选科信息应与基础信息一致。中文排名可留空，不一致时系统提醒。

总分赋分可直接提供；未提供时，只有六科有效成绩齐全才会汇总。空白、缺考、未选考与有效零分含义不同，不要混用。

## 导入

1. 打开数据管理，上传基础信息，核对班级数和学生数。
2. 选择成绩文件，填写届别、考试名称和考试月份，然后预检。
3. 查看阻止项和提醒项。缺少已选科目赋分的行不能入库；修正源表后重传。
4. 上传排名差异可以在确认后继续；展示以系统计算排名为准。
5. 确认入库。重复数据按页面提示选择取消、追加或覆盖，不要把不同考试填成同一场。

基础信息学校名与现有学校不一致会报错。若当前是系统演示数据，请先在数据管理顶部确认清除演示数据，再导入本校文件。下方“清除全部上传数据”处理的是上传批次，与演示清理不同。

## 分析

选择单次考试、历次考试和方向后应用筛选。年级数据页显示自动均分和覆盖人数；班级筛选只影响展示，不改变年级比较基准。请核对是否已导入全年级，系统不会替你假设数据完整。

设置特控、211、985 等分数线和班级目标后，查看上线、达标、临界以及分数段。临界窗口的上边界不包含上线分数本身；达到分数线计入上线。个体追踪需要选择具体学生，比较各次考试自己的方向、均分和排名。

本系统分析上传的赋分，不负责按各省规则重新赋分；不同科目和方向不得混用口径。字段含义与公式见[核心业务规则](核心业务规则.md)。

## 导出

导出中心只提供班级成绩表：选择届别、一次或多次考试及班级，下载 ZIP 压缩包后解压为各班 Excel 表。表中包含学科原始分、赋分及系统计算的年级排名。文件会保留实际所选范围，不受页面分页限制。打开下载结果核对考试名称、人数及方向。

导出文件由程序生成，无需另放导出标准工作簿。导出包含学生姓名；分享前请自行检查并处理个人信息。

## 备份和退出

从左下角选择“完全退出程序”，等待退出完成后备份整个 `%LOCALAPPDATA%\StudentScoreAnalysis` 目录。备份含学生隐私，请妥善保存，不提交到 GitHub。恢复前关闭程序，保留当前备份，再由了解数据结构的人员处理；不要直接覆盖正在使用的数据库。

如果关掉浏览器，再双击快捷方式可以打开当前实例。若无法启动，查看数据目录中的 `logs/app.log`，不要将数据库或学生信息随日志一起公开。
